# Security and password policy

LexZim does not offer a self-service email reset link. A Managing Partner (or staff with `users.manage`) must create users and approve resets.

## Password rules

- Minimum **10 characters**.
- Temporary passwords are generated by the system when you leave the invite password blank.
- Temporary passwords are shown **once** to the creator. Copy them immediately. They cannot be retrieved later.
- New users (and approved resets) must **change password on first login**. A banner in the app prompts until they do.

Never send passwords in public chat. Prefer a phone call or a secure channel.

## Creating users

Path: **User access** (`/staff`). Permission: `users.manage` only.

1. Full name, email, role.
2. Leave password blank to auto-generate, or type a temporary password (min 10).
3. Copy the one-time password from the callout and give it to the user.
4. Seat limits come from the licence. Deactivate unused logins before inviting if seats are full.

HR staff records (`/hr/staff`) are not logins. See `HR_Quickstart.md`.

## Forgot password

1. On the login screen, enter email and click **Forgot / request password reset**.
2. The screen always shows a generic confirmation (it does not say whether the email exists).
3. A Managing Partner opens **Settings → Security**, reviews the queue, and clicks **Approve and issue** or **Reject**.
4. On approve, a new temporary password is shown **once**. Share it with the user. They must change it after sign-in.

There is no reset email. That is deliberate so account recovery stays under firm control.

## Session timeout

Staff sessions end after **30 minutes of inactivity** (no mouse, keyboard, or touch). Active work does not log you out on a fixed clock from sign-in. After idle sign-out, the login screen shows a calm message so you can sign in again. Same rule as `FAQ.md`.
