# LexZim exports (Phase 7 P7-02)

Server-generated **PDF**, **Word (.docx)**, and **Excel (.xlsx)** downloads with firm branding. Official reports must use this path (not browser-only print).

## Architecture

```
lib/export/
  types.ts              Shared ExportDocument + formats
  branding.ts           Firm letterhead from `firms` + profile fields
  to-pdf.ts             pdfkit renderer
  to-docx.ts            docx renderer
  to-xlsx.ts            exceljs renderer
  download-response.ts  Attachment HTTP helpers
  registry.ts           Export kind → data loader + permissions
  reports/              Kind-specific document builders
    debtors-document.ts

app/api/export/[kind]/route.ts   GET ?format=pdf|docx|xlsx|csv
components/export/ExportMenu.tsx UI dropdown
```

## API

```
GET /api/export/{kind}?format=pdf|docx|xlsx|csv&…filters
```

| Kind | Permission | Filters (query) |
|---|---|---|
| `debtors` | `billing.view` | `matterId`, `clientId`, `bucket`, `from`, `to` |
| `gl_coa` | `finance.gl.view` | none |
| `gl_trial_balance` | `finance.gl.view` | `asOf` |
| `gl_profit_and_loss` | `finance.gl.view` | `from`, `to` |
| `gl_balance_sheet` | `finance.gl.view` | `asOf` |
| `quotation` | `billing.view` | `id` (quotation UUID) |
| `invoice` | `billing.view` | `id` (invoice UUID) |
| `receipt` | `billing.view` | `id` (fee payment UUID) |
| `trust_statement` | `trust.view` | `clientId` |
| `petty_cash_summary` | `finance.view` | none |
| `creditor_ageing` | `finance.view` | none |
| `birthday_list` | `crm.view` | `month`, `responsibleLawyerId` |
| `lawyer_performance` | `reports.view` | `from`, `to` |
| `practice_report` | `reports.view` | `type` (ar-aging, time, trust-balances, trust-movements, workload, upcoming), plus report filters |
| `finance_weekly` | `finance.view` | `asOf` |
| `finance_monthly` | `finance.view` | `year`, `month` |

Responses are file downloads. Sensitive exports write an audit log (`export.debtors`, etc.).

## Branding

From `firms` row per tenant:

- Firm name, address lines, contact email/phone
- `logoUrl` reserved for future PDF header image (P7+ polish)
- Footer: **Generated by LexZim**

## Adding a new export kind

1. **Build document** — `lib/export/reports/{kind}-document.ts`  
   Map repo data → `ExportDocument` (title, columns, rows, summary).

2. **Register** — in `lib/export/registry.ts`:
   ```typescript
   my_report: {
     permission: "finance.view",
     auditAction: "export.my_report",
     filenameBase: "lexzim-my-report",
     buildDocument: async (ctx) => { … },
     buildCsv: async (ctx) => { … }, // optional
   }
   ```

3. **UI** — `<ExportMenu kind="my_report" queryParams={…} />`

4. **Docs** — add row to the API table above.

## Renderers

All three formats consume the same `ExportDocument`:

| Field | Purpose |
|---|---|
| `title`, `subtitle`, `note`, `asOf` | Header block |
| `summaryLines` | KPI lines above table |
| `columns` | Table headers + keys |
| `rows` | Pre-formatted string cells |

Keep **formatting in the document builder** (currency, dates, labels). Renderers stay dumb.

## Performance notes

- PDF paginates long tables (~28 rows before optional page break).
- Excel uses exceljs `writeBuffer` (fine for desk-scale reports).
- For very large extracts (10k+ rows), prefer CSV or stream Excel in a later prompt.

## Pilot

**Debtors** (`Finance → Debtors`) uses `ExportMenu` with PDF, Word, Excel, and CSV.

Legacy `GET /api/finance/debtors?format=csv` remains for backward compatibility.
